#5 Stev - 2011-03-11 10:13 (86.41.138.XXX)
A server defines an RL pickup as when a player picks up an item which causes him to have an RL where he did not previously have one.

This means that packs count as RL pickups, as well as the RL item itself.
However, it also means that picking one up when you already have one does not count as an RL pickup.
