Signups, maps and more

2011-08-24 08:28 by Hooraytio

We should have opened the signups by now so here is some information regarding that, the map pool and more.

Due to the qw.nu domain being offline for a couple of days we havent been able to put up the EQL14 page and start taking signups. However, we will try to get the EQL14 signups online as soon as possible. In the meantime you can always gather the old team and prepare with some pracs since its always easier for us when making divisions if we have some pracs to look at as well.

The map pool in EQL14 will be TB3. This because of not getting enough knowledge on which maps to include because of variating information of the quality of the maps, so we will need more time to see how they will work out in reality. That is why there is a plan on running a "kenya" tournament in order to figure out wich maps could be used to widen the pool to 5 or 7 maps in the future.

For that to happen we need a few new admins with interest in the "kenya" scene to help out with selecting maps and running the kenya league. You can also apply for an admin position in the regular league since we need help on that side as well, but we mostly need to know if there are new admins ready to run a kenya tournament.

Be patient and good things will follow!
